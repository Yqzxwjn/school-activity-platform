## 三、运行环境对照

| 说明书要求 | 本项目实现 | 说明 |
| --- | --- | --- |
| B/S 架构 | 是 | 浏览器直接访问，无客户端安装 |
| 服务端操作系统 | 不限定 | Windows Server 或 Linux 均可运行，提供 Docker 镜像 |
| Web 服务器 | 内置 Node HTTP 服务 | 生产建议用 Nginx / Caddy 反向代理并配置 HTTPS |
| 后端运行环境 | Node.js 22.5 及以上 | 使用 Node 内置 SQLite，无第三方依赖 |
| 数据库 | SQLite（Node 内置） | 表结构与说明书的数据模型一一对应，见《源代码说明》第二节 |
| 客户端浏览器 | Chrome / Edge / Firefox / Safari | 原生 ES5 语法，不使用前端框架与打包工具 |
| 数据持久化 | 服务端数据库 + 会话 | 不再依赖浏览器本地存储，多用户共享同一份数据 |
